## Conventions

- All dimensions **millimetres**; drawings **NTS — do not scale**.
- Clear height assumed 2,850; false-ceiling levels (per D3) shown dashed.
- Metric governs — the base layout's imperial sub-dimensions carry a ~1.55× conversion
  error (flagged to Archiethos). Re-verify all dimensions by laser before production.
- Design intent only — **not for construction**; D12 BOQ governs commercial scope.
- Items marked `*` or VERIFY fall short of target clearances pending site measurement
  (BR2 door-to-slider path 870 vs 900; dry-balcony passage 475 vs 550).
